# Roadmap

dewatermark aims to be the most trustworthy open-source toolkit for inspecting and mitigating text watermark artifacts—not the loudest universal-removal claim.

## Implemented on main — v0.6 release candidate

- Dependency-free KGW-, Unigram-, and tournament-style contract fixtures,
  detector inventory/doctor/conformance commands, a real pinned upstream KGW
  token-ID pack, and a fail-closed SynthID Text integration template
- Preregistered benchmark protocol registry, blinded observation/review
  artifacts, schema-validated evidence bundles, replication records, resource
  telemetry, fixed-FPR clustered inference, and content-addressed replay inputs
- Required/advisory bidirectional NLI, atomic claim/QA, entity, citation, and
  task quality-gate contracts with cached-only model behavior
- Shared cross-platform process-tree termination for detector/evaluation
  adapters, repository scanner configuration, and agent-skill installation
- VS Code and JetBrains local-scanner proofs of concept, checked-in OpenAPI,
  pinned client generation, npm packaging, and signed GHCR release automation

## Carried forward — unpublished v0.5 development milestone

- Detector-scoped assurance receipts and explicit unsupported states
- Content-bound inspect → plan → apply → verify workflows for agents
- Bounded independent-detector command adapter and conformance kit
- Context-aware cross-runtime Unicode policy and reversible scanner fixes
- Hardened HTTP/MCP transports, release supply chain, and benchmark manifests

## Next — empirical evidence, not broader claims

- Publish a calibrated natural-language KGW/Unigram benchmark with disjoint
  populations, held-out keys, independent detection, adequate matched controls,
  human review, and an external replication record
- Complete an operator-configured SynthID Text reference replication without
  implying access to Gemini production keys or configuration
- Publish the npm module, GHCR image, editor packages, and generated SDKs after
  their external trusted-publisher/marketplace identities are configured
- Run multilingual/task-specific learned-gate calibration and human validation
- Host and version signed aggregate evidence bundles in a public registry

## Later

- Point `llmwatermarkremover.com` at the documentation/SEO site after DNS and
  GitHub Pages custom-domain verification are complete
- Community-maintained detector matrix and independent replication reports
- Provider-authorized adapters when public technical interfaces become available
